### 电解质（W5 起必加，9% 必经之路）

低体脂 + 高有氧 = 钠钾镁流失加速，**不补会出现抽筋、头晕、力量崩盘**。

| 电解质 | 日需量 | 来源 |
|---|---|---|
| 钠 (Na) | 3000-5000 mg | 食盐 + 训中补 |
| 钾 (K) | 3500-4700 mg | 香蕉/菠菜/土豆/椰子水 |
| 镁 (Mg) | 400 mg | 甘氨酸镁补剂 + 深绿叶菜 |

**训中电解质方案（W5 起）**：
- 1L 水 + 1g 海盐 + 1g 氯化钾（药店可买）+ 50mg 镁
- 或：电解质粉（推荐 LMNT 或国产无糖款，1 包/训练）

### 咖啡因 / 茶
- 早 1 杯黑咖啡（150mg），训前 1 杯（150-200mg）
- **下午 3 点后禁咖啡因**
- 无糖绿茶/普洱不计入总水量，可作为下午饮品

## 九、refeed lunch（D5 周日中午）选项

**热量目标**：1000-1200 kcal · 高碳水 · 中蛋白 · 低脂

| 选项 | 内容 | 优点 |
|---|---|---|
| **寿司套餐** | 鱼生寿司 16-20 贯 + 味噌汤 + 毛豆 + 茶 | 蛋白足 + 钠适中 + 心理满足 |
| **韩式烤肉** | 牛肉 200g + 白米饭 1.5 碗 + 蔬菜包肉 + 泡菜 | 大餐感强 |
| **日式拉面** | 1 碗豚骨/酱油 + 叉烧加量 + 半熟蛋 + 海苔 | 高碳水补糖原 |
| **意面套餐** | 番茄海鲜意面 1 大份 + 沙拉 + 全麦面包 | 碳水量大 |
| **中式米饭套餐** | 白米饭 200g + 红烧鸡腿 + 清炒时蔬 + 紫菜蛋花汤 | 自做最易控 |

**禁忌**：
- ❌ 甜饮料、奶茶、果汁
- ❌ 油炸食物（炸鸡、薯条）
- ❌ 蛋糕、冰淇淋、甜点
- ❌ 含糖酒类

**Refeed 后**：当晚晚餐恢复正常 D 阶段配置，**不要因为吃了多就跳餐**。

## 十、外食策略（手术日 / 应酬）

### 中餐外食
- **优先**：清蒸鱼 / 白切鸡 / 牛腩 + 米饭半碗 + 清炒蔬菜
- **可吃**：黑椒牛柳（要求少油）、烤鸡腿（去皮）、虾仁滑蛋（少油）
- **避免**：糖醋、红烧、糖醋里脊、地三鲜、京酱肉丝

### 日韩餐
- 寿司、刺身、烤肉（自烤无糖腌料）、味噌汤
- 避免天妇罗、炸物、照烧（含糖）

### 西餐
- 牛排（菲力/西冷，五分熟少酱）+ 烤蔬菜
- 鸡胸沙拉（vinaigrette 不加奶油酱）
- 避免奶油意面、披萨、芝士焗

### 快餐（应急）
- Subway：火鸡胸/烤鸡 6 寸全麦 + 蔬菜 + 醋汁，不加芝士酱
- 麦当劳/KFC：烤鸡腿堡（去皮）+ 玉米杯，**不要薯条不要可乐**
- 便利店：茶叶蛋 3-4 个 + 烤红薯 1 个 + 无糖豆浆 + 鸡胸即食

## 十一、烹饪 SOP

### 用油原则
- 烹饪油：橄榄油（中低温）、椰子油（高温煎）
- **每日总油摄入 ≤ 15ml**（含烹饪 + 凉拌）
- 测量：用 1 汤匙（15ml）作为基准

### 推荐烹饪方法
✅ 蒸 / 煮 / 烤箱烤 / 不粘锅煎（薄油）/ 凉拌 / 卤
⚠️ 炒（控油）/ 焖
❌ 油炸 / 红烧加糖 / 糖醋

### 调味白名单
- 海盐、黑胡椒、白胡椒、五香粉、辣椒粉、孜然、咖喱粉
- 蒜末、姜末、葱、香菜
- 酱油（低钠款，每餐 ≤ 5ml）、米醋、苹果醋
- 柠檬汁、芥末（不加蛋黄酱的纯芥末）
- 罗勒、迷迭香、百里香

### 调味黑名单
- 糖、蜂蜜、枫糖浆（W4 起严禁）
- 沙拉酱（千岛/凯撒/蛋黄酱）
- 蚝油（含糖）、甜面酱、海鲜酱、烧烤酱
- 番茄酱（含糖）、寿喜烧酱

## 十二、Batch Cook 每周 SOP（周日 90 min）

### 购物清单（一周量）

**蛋白源**
- 鸡胸 1.5kg
- 牛腱 / 牛霖 1kg
- 鳕鱼/鲈鱼 600g（分 3 餐）
- 大虾 400g（冷冻）
- 鸡蛋 30 个
- 希腊酸奶（0 糖）500g（备用零食）

**碳水**
- 大米（糙米+白米 1:1）2kg
- 燕麦 500g
- 红薯/紫薯 1.5kg
- 全麦面包 1 袋
- 香蕉 10 根
- 蓝莓（冷冻）500g

**脂肪**
- 牛油果 4 个
- 原味杏仁 200g
- 橄榄油 500ml

**蔬菜**（3-4 天采购一次新鲜）
- 西兰花 1kg
- 芦笋 500g
- 菠菜 500g
- 番茄 500g
- 黄瓜 500g
- 洋葱 / 大蒜 / 生姜

### 周日 90 分钟流程

```
0-15 min   烤箱预热 200°C
           鸡胸切均匀厚度，盐+黑胡椒+橄榄油按摩
           牛腱清水+姜葱冷水下锅

15-45 min  鸡胸入烤箱 25 min
           糙米白米 1:1 蒸 1kg
           红薯整个蒸锅入锅

45-60 min  牛腱继续炖
           西兰花/芦笋焯水后冰水镇凉，沥干分装
           
60-75 min  鸡胸出炉静置切片分 5 份（每份 150g 净）
           米饭分装 5×200g
           红薯切块分装

75-90 min  牛腱出锅切片分 5 份
           煮 8 个茶叶蛋（备用蛋白源）
           所有容器入冰箱（3 天内吃完）
```

**冷冻保存**：超过 3 天的鸡胸/牛腱分装冷冻，吃时前一晚转冷藏解冻。

## 十六、应急 FAQ

### Q：饿到睡不着怎么办？
- 200g 黄瓜片 + 100g 鸡胸丝（蘸辣椒粉）
- 1 杯无糖豆浆 + 250g 西兰花
- **不吃水果**（睡前果糖储脂）

### Q：手术日跳过午餐？
- 训前加餐位置吃午餐（17:00）
- 训后 + 晚餐合并为一餐（20:00 后吃）
- 该日总量按 -200 kcal 处理（少 1 餐量）

### Q：周六应酬喝酒？
- **建议不喝**，但若必须：
  - 选清酒/红酒/伏特加苏打（无糖）
  - 1-2 杯上限
  - 当天晚餐砍掉 200 kcal 脂肪
  - **次日不补**，按计划进行

### Q：训练状态崩了？
- 连续 3 天训练重量下降 → 当周 +200 kcal（碳水）
- 单次不算，可能是睡眠/工作压力

### Q：体重连续 5 天不降？
- 检查：饮水是否够？睡眠？步数？
- 大概率是水分滞留（皮质醇高/月初/盐摄入波动）
- **不要进一步砍热量**，先检查执行精度

### Q：极度想吃甜的？
- 0 卡可乐 / 元气森林
- 无糖巧克力（赤藓糖醇）20g 以内
- 蓝莓 + 0 糖希腊酸奶 + 肉桂粉
- **D5 refeed 提前消费**（次日少 200 kcal 补）
