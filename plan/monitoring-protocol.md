# 动态监测协议 v2

> 从被动记录升级为主动信号捕捉 + 自动触发调整。

---

## 一、每日 4 检测点

| 时段 | 命令 | 数据点 | 输出 |
|---|---|---|---|
| 07:30-08:30 | `/morning` | 晨重、睡眠 h/质量、精神、晨脉 | 当日训练上不上 |
| 12:30-13:30 | `/mid` | 能量、食欲、DOMS、消化、压力 | 训前餐 + 训练微调 |
| 训后 | `/post` | 训练数据、训后精神、关节痛 | 下次重量 + e1RM |
| 23:00-23:30 | `/night` | kcal/水/步数/LISS/上床时间 | 7 日趋势 + 预警 |

---

## 二、红色触发（立即降负荷）

| 信号 | 阈值 | 动作 |
|---|---|---|
| 单日睡眠 | < 5h | 当日改 D5 或完休 |
| 训前能量 | < 5/10 | 主项 -5~10% |
| 主项 RPE | > 目标 +2 | 当组停，剩余 -5% |
| 关节尖锐痛 | 出现 | 砍当日剩余 |
| 晨重 vs 7日均值 | +1.5kg 非 refeed 次日 | 排查（不焦虑）|

---

## 三、黄色警告（连续 2-3 天）

| 信号 | 连续 | 调整 |
|---|---|---|
| 睡眠 < 6h | 3 天 | 砍当周 1 次训练 + kcal +150 |
| 精神 ≤ 5 | 3 天 | D5 轻量 / kcal +100 |
| 食欲 < 4 | 3 天 | 加 EAA + 检查吸收 |
| 主项 RPE 高 +1 | 2 次 | 维持重量 |
| 主项力量回落 | 2 次 | kcal +200（碳水）|

---

## 四、绿色加码

| 信号 | 触发 | 动作 |
|---|---|---|
| 主项 RPE 低 -2 | 2 次同动作 | 主项 +2.5kg |
| 7日睡眠 ≥ 7.5h | — | 可提前进入下阶段 |
| 7日精神 ≥ 8 | — | 弱项 +2 组 |

---

## 五、5 个生活信号矩阵

| 信号 | 频率 | 评分 | 异常解读 |
|---|---|---|---|
| 食欲 | 每餐前 | 1-10 | 持续低 = 瘦素低/应激高 |
| 晨脉 | 每日 | bpm | 高于基线 +7 = 过度训练 |
| 排便 | 每日 | 次数+形状 | 0 次/天 ≥ 3 天 → 纤维不足 |
| 工作压力 | 每日临睡 | 1-10 | ≥7 持续 → 皮质醇杀手 |
| 关节痛 | 每日 | 0-5 + 位置 | 同部位 3 天 → 调整动作 |

---

## 六、主动追踪时机（Claude 主动开口）

| 时间 | 自动行为 |
|---|---|
| 早 08:00 后无 /morning | 追问晨数据 |
| 下午 17:30 前训练日 | 追问能量+训前餐 |
| 训练日 21:00 后无 /post | 追问训练完成 |
| 23:30 前无 /night | 追问上床时间 + 提醒补剂 |
| 任何指标命中红色触发 | 立刻分析 + 方案 |

---

## 七、Claude 当前状态机（实时）

- 每次 session 启动读 `logs/daily.jsonl` 最近 7 行
- 自动检测：连续 X 天睡眠 < 6h / 精神 ≤ 5 / 主项 RPE 高 → 触发预警
- 自动检测：训练日是否已 `/post` → 追问
- 自动检测：周日是否已 `/week` → 提醒
