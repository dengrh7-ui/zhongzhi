description: 周日复盘 + 7 日趋势分析 + 下周调整决策
---

执行周复盘（**周日早晨 7:30 后触发**）：

1. **询问周日早数据**：
   - 晨重
   - 腰围
   - 三张照片是否已拍

2. **读取数据**：
   - `logs/daily.jsonl` 最近 7 行
   - `logs/training.jsonl` 最近 5 行
   - `plan/current-week.md` 当前阶段

3. **生成周报**：

```
📊 W{N} 周复盘报告（{start_date} - {end_date}）

═══════════════════════
🎯 阶段：{阶段名} · 目标 kcal: {target}
═══════════════════════

📈 关键指标
   体重：起 {start}kg → 末 {end}kg（Δ {diff}）
   7 日均值：{avg}kg
   腰围：起 {start_w}cm → 末 {end_w}cm（Δ {diff}）
   睡眠均值：{sleep_avg} h
   精神均值：{mental_avg}/10

🏋️ 训练总结
   完成训练日：{x}/5
   主项进展：
     胸（上斜卧推）：{w1}→{w2}
     肩（站姿推举）：{w1}→{w2}
     背（硬拉）：{w1}→{w2}
     腿（深蹲）：{w1}→{w2}
     腿后链（RDL）：{w1}→{w2}
   总训练容量：{total_volume}（vs 上周 {Δ}）

🍽️ 饮食执行
   平均日 kcal：{actual} / 目标 {target}（{compliance}%）
   平均 C/P/F：{c}/{p}/{f}
   refeed lunch：{是否完成}

💧 生活
   平均饮水：{water} L
   平均步数：{steps}
   LISS 总计：{liss_total} min
   HIIT 次数：{hiit_count}

═══════════════════════
🔍 趋势判断
═══════════════════════

{基于 7 日均值 vs 目标的判断：}
- 体重下降 vs 阶段目标：{超前/达标/落后}
- 力量保持情况：{up/stable/down}
- 恢复质量：{good/medium/poor}

═══════════════════════
🎯 下周调整决策
═══════════════════════

W{N+1} 阶段：{下周阶段}
目标 kcal：{X}（{增/减 X kcal}）
碳水：{C}g  蛋白：{P}g  脂肪：{F}g

主项调整：
  胸：{w} → {new_w}
  肩：{w} → {new_w}
  背：{w} → {new_w}
  腿：{w} → {new_w}
  腿后链：{w} → {new_w}

弱项加码：
  {1-2 个本周表现不足的弱项 → 下周补量方案}

生活节奏：
  {基于本周睡眠/精神的调整建议}

═══════════════════════
📸 照片对比（提醒拍照）
═══════════════════════
   [ ] 正面松弛（同光同角度）
   [ ] 侧面松弛
   [ ] 背面松弛
   [ ] 与 W1 D1 基线照对比

═══════════════════════
✅ 下周纪律清单
═══════════════════════
{基于本周问题，列 3-5 条优先改进}
```

4. **更新 `plan/current-week.md`**：
   - 写入 W{N+1} 的目标参数
   - 主项目标重量
   - 饮食目标
   - 本周重点提醒

5. **写入 `logs/weekly.md`**：
   - 追加本周复盘摘要（精简版）
