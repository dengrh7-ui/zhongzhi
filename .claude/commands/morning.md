description: 晨起数据录入（晨重/腰围/睡眠/精神）
---

执行用户的晨起数据录入流程：

1. **询问 5 项**（如果用户已在消息中提供，直接提取，不再问）：
   - 晨起体重（kg，精确到 0.05）
   - 腰围（cm，**只在周日早测**，工作日不必问）
   - 昨晚入睡时间 + 今早醒来时间 → 算睡眠时长
   - 昨晚睡眠质量 1-10
   - 全天预估精神状态 1-10

2. **写入 `logs/daily.jsonl`**：
   - 追加一行 JSON
   - 字段：`date, weight, waist, sleep_h, sleep_quality, mental, kcal, C, P, F, water_L, steps, liss_min, hiit, training, bed_time, notes`
   - 未知字段先填 null，后续命令补全

3. **趋势分析**（读取 daily.jsonl 最近 7 行）：
   - 与基线（76.65kg / 78cm）对比
   - 与 7 日均值对比
   - 与昨日对比
   - 判断是否在 W{N} 周度目标轨道上

4. **反馈输出格式**：
```
✅ 已记录 {date} 晨数据

📊 本次数据：
   体重：{w} kg（vs 昨日 {Δd}，vs 7日均 {Δw}，vs 基线 {Δb}）
   睡眠：{h} h（质量 {q}/10）
   精神：{m}/10

📈 趋势判断：
   {analysis - 是否符合阶段预期}

🎯 今天注意：
   {基于数据的1-2条建议}
```

5. **特殊判断**：
   - 体重单日波动 > 0.8kg → 解释为水分波动，不焦虑
   - 睡眠 < 6h → 建议今天降一档训练
   - 精神 < 5 → 建议改 D5 轻量或休息
   - 周日额外触发 `/week` 提示
