执行午检（12:30-13:30 训练日触发）：

1. **询问 5 项**：
   - 训前能量 1-10
   - 食欲 1-10（午餐前/后）
   - 肌肉酸痛位置（昨日训练部位的当前 DOMS 评分 0-5）
   - 消化感（胃胀/正常/饥饿）
   - 当前工作压力 1-10

2. **基于晨数据 + 午检综合判断**：
   - 晨重 + 睡眠 + 食欲 = 当日能量曲线预测
   - DOMS 位置 vs 今日训练计划 = 是否需要调整动作选择

3. **输出训前餐 + 训练调整建议**：

```
🕐 午检 · {date} 12:XX

📊 当前状态：
   训前能量：{e}/10
   食欲：{a}/10
   DOMS：{部位} {0-5}
   工作压力：{s}/10

⚡ 训前餐建议（17:45 吃）：
   {基于能量分调整}：
   - 能量 ≥ 7：标准训前餐（碳水 45g + 蛋白 22g）
   - 能量 5-6：训前餐 +1/3（碳水 60g）
   - 能量 ≤ 4：训前 +咖啡因 200mg + 红牛 / 改 D5 轻量

🏋️ 今日训练调整：
   {基于综合状态}
   - 主项：{w} × {reps}（vs 计划 {plan_w}）
   - 注意：{1 条关键提醒}

⚠️ 触发警告（如有）：
   - 食欲连续 < 4 → 检查蛋白吸收
   - DOMS 同部位 ≥ 4 → 避开相关动作
   - 工作压力 ≥ 8 → 训练量降 10%
```

4. **不写入文件**（决策辅助命令）
