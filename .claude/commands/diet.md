执行饮食录入与核算：

1. **接收用户输入**：
   - 用户描述吃了什么（可以是一餐或全天）
   - 格式自由：「早餐 30g 燕麦 + 2 全蛋」或「全天：早..午..晚..」

3. **核算并写入 `logs/daily.jsonl`** 当日记录的 `kcal/C/P/F` 字段：
- 如已有当日记录，**累加**到现有值
- 如无，新建一行

4. **对照本周目标输出**：

根据 CLAUDE.md「四、4 阶段营养」表，找出本周目标。

```
✅ 已记录 {date} 饮食

🍽️ 本次餐次：
   {餐次} = {kcal} kcal · C{C} P{P} F{F}

📊 全天累计：
   kcal: {now}/{target}  剩余 {gap}
   C:    {now}/{target}  剩余 {gap}
   P:    {now}/{target}  剩余 {gap}
   F:    {now}/{target}  剩余 {gap}

🎯 剩余餐次建议（基于现有缺口）：
   {1-2 条具体食物建议}

⚠️ 警告（如有）：
   - 蛋白完成 < 80% 且已过 18:00 → 提醒补
   - 脂肪过半但 < 50% 蛋白 → 调整下一餐结构
   - 总 kcal 已超 110% → 降晚餐主食
```
