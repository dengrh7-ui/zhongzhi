# 成都 → 新疆 深度Local游攻略（6-7人 · 16天）

> 思路：不走"独库公路网红打卡 + 喀纳斯+禾木"的标准路线，走**北疆牧民转场季 + 南疆巴扎人间烟火**，住毡房/民宿/老城客栈，吃牧民家访 + 夜市 + 馕坑现烤。6-7人正好包一辆**丰田考斯特(17座)** 或 **2辆陆巡**，性价比远高于跟团。

## 三、Local化关键操作（保证"不像游客"）

### 1. 证件类
- **边防证**：禾木白哈巴、塔县、红其拉甫必备。出发前在户籍地派出所办理免费，比新疆当地办快
- 身份证随时带，南疆有检查站

### 2. 装备类（共用清单）
- **越野睡袋**（毡房+牧区温差10-30℃）
- **海拔药**：红景天+丹参滴丸，帕米尔段必备
- **现金**：南疆部分牧区微信信号差，备¥2000现金
- **小礼物**：内地茶叶/糖果，送毡房主人比给钱受欢迎

### 3. 吃喝的"内行点单"
| 场景 | 不要点 | 应该点 |
|------|--------|--------|
| 大盘鸡 | 景区¥188大盘 | 沙湾县当地店¥80带皮带面 |
| 烤肉 | 旅游街¥10/串 | 找**红柳枝**(不是铁签)+本地人多的摊¥5 |
| 抓饭 | 酒店自助 | 喀什**艾日提**百年抓饭店¥15/份 |
| 酸奶 | 超市瓶装 | 巴扎现舀**老酸奶**+蜂蜜¥5 |
| 馕  | 机场礼盒装 | 馕坑刚出炉**窝窝馕**¥2 |

### 4. 避开"假Local"陷阱
- 喀什**古城西区**是2010年重建的，**东区**(吾斯塘博依)才是老的
- 喀纳斯"图瓦人家访"99%是演员；真实图瓦人在**禾木徒步路上**的散居点
- 那拉提"空中草原"是索道项目，**巩乃斯林场**才有真牧民
- 不要在巴扎跟摊主"砍价拍照"——花¥5买东西就能拍

### 5. 摄影/拍照礼仪
- 拍维吾尔/塔吉克老人前一定要**先打招呼**(亚克西木塞孜)
- 清真寺礼拜时间不要进入也不要拍
- 牧区拍羊群可以，拍人先问

## 五、最佳出行时间
- **6月下-7月初**：薰衣草(伊犁霍城) + 牧民转场 + 雪山未化
